# Auditoría técnica de la web actual

Revisión de la versión pública de [`ilopex.com`](https://ilopex.com/) realizada el 21 de
agosto de 2026.

- Es una sola página generada por Hostinger Website Builder.
- No hay formularios ni funcionalidad que requiera API o base de datos.
- El contenido publicado solo está en inglés.
- La jerarquía de encabezados salta de `h1` a `h6`, `h4` y `h5`.
- Se observaron ocho imágenes sin texto alternativo.
- Open Graph y Twitter declaran una imagen vacía.
- El enlace «See all experience» vuelve a la propia portada.
- Solo existe `hreflang="x-default"`; no hay rutas de idioma.
- CSS, tipografía e imágenes dependen de la infraestructura de Zyro/Hostinger.

La nueva base corrige la estructura, localización y portabilidad. El diseño y la
migración de activos quedan expresamente fuera de esta fase.
